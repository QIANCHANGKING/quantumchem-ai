# Origin 2024b 图形模板目录

将对应图类型的自定义 `.otpu` 模板放在此目录中，`OriginRenderer` 会自动按 `<kind>.otpu` 加载应用：

- `levels.otpu` / `levels_compare.otpu`
- `spin.otpu`
- `dos.otpu`
- `orb_comp.otpu`
- `spin_ladder.otpu`
- `isomer_ranking.otpu`
- `size_evolution.otpu`
- `vde_ade.otpu`
- `s2.otpu`

🧑 P6 检查点：首次生成初版图形后，可在 Origin 2024b 中打开对应 `.opju` 微调字体、线宽与配色，然后“另存模板”为上述 `.otpu` 文件。未提供 `.otpu` 时会自动使用 Origin 内置默认模板。
