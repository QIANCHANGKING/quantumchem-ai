# cclib Gaussian 16 测试样本来源

本目录中的 Gaussian 输出文件全部来自 **cclib** 官方仓库的公开测试集（BSD 3-Clause 协议）：

- 仓库：`https://github.com/cclib/cclib`
- 路径：`data/Gaussian/basicGaussian16/`
- 文件：
  - `dvb_sp.out`（闭壳层单点）
  - `dvb_gopt.out`（闭壳层几何优化）
  - `dvb_ir.out`（闭壳层频率与热力学量）
  - `dvb_un_sp.log`（开壳层单点，含 `<S²>`、α/β 轨道与 Mulliken 自旋布居）
  - `Mo4OCl4-sp.log`（过渡金属团簇阴离子单点）
